# 🏛 Мониторинг наградных указов СЗФО

Ежедневный автоматический дайджест награждённых государственными наградами из **10 регионов Северо-Западного федерального округа**. Данные — с официального портала <http://publication.pravo.gov.ru>.

## Как это работает

- **GitHub Actions** каждый день в 9:00 МСК скачивает наградные указы за вчера, распознаёт PDF через Tesseract OCR, извлекает награждённых из регионов СЗФО и коммитит готовый HTML в репозиторий.
- **GitHub Pages** раздаёт готовые HTML-файлы по публичному URL.
- **Пользователи** просто открывают ссылку в браузере и мгновенно видят свежий дайджест и архив за все дни.

## Развёртывание (10 минут, один раз)

Нужен только бесплатный аккаунт на GitHub (email + пароль, никаких карт).

### Шаг 1. Регистрация

<https://github.com/signup> → email → пароль → username.

### Шаг 2. Создание репозитория

1. <https://github.com/new>
2. **Repository name:** `szfo-monitor` (или любое)
3. **Public** ← обязательно, иначе GitHub Actions на public-репо будет ограничен
4. **Add a README file** — снимите галку, README у нас свой
5. **Create repository**

### Шаг 3. Загрузка файлов

На странице свежего репозитория нажмите **uploading an existing file** (ссылка в тексте) или **Add file → Upload files**.

Перетащите **все 4 файла из этого комплекта** сразу:

- `generate.py`
- `requirements.txt`
- `.gitignore`
- `.github/workflows/generate.yml` ← папка `.github/workflows/` создастся автоматически, если сохранить структуру при перетаскивании

Внизу поле «Commit changes» → **Commit changes**.

> **Важно про `.github/workflows/generate.yml`:** файл должен лежать именно в папке `.github/workflows/`. Если веб-интерфейс GitHub при перетаскивании сплющил структуру — создайте папку вручную: **Add file → Create new file**, введите путь `.github/workflows/generate.yml`, вставьте содержимое, коммит.

### Шаг 4. Включение GitHub Pages

1. **Settings** (в шапке репо)
2. Слева в меню **Pages**
3. **Source: Deploy from a branch**
4. **Branch: main** / **Folder: `/ (root)`**
5. **Save**

Через 1-2 минуты вверху появится плашка с URL: `https://ВАШ-USERNAME.github.io/szfo-monitor/` — это будущий адрес дайджеста.

### Шаг 5. Первый запуск workflow

Автоматически он запустится завтра в 9:00 МСК. Чтобы получить первый отчёт сразу:

1. Вкладка **Actions** (в шапке репо)
2. Слева выберите **Ежедневный дайджест СЗФО**
3. Справа кнопка **Run workflow** → **Run workflow**
4. Дождитесь окончания (5–10 минут, прогресс виден в реальном времени)

По завершении в репозитории появятся файлы:
- `index.html` — главная страница
- `reports/YYYY-MM-DD.html` — отчёт за день
- `reports/YYYY-MM-DD.json` — сырые данные
- `reports/index.json` — список дат

Через минуту после коммита GitHub Pages обновится, и по URL из шага 4 будет виден дайджест.

### Шаг 6. Раздача ссылки

Ваш публичный URL: **`https://ВАШ-USERNAME.github.io/szfo-monitor/`**

Этой ссылкой можно делиться с любым количеством пользователей — регистрация не нужна, они просто открывают её в браузере. Дайджест обновляется автоматически каждый день.

## Запрос за конкретную дату (для админа)

Если нужен отчёт за произвольную дату (не за вчера):

1. **Actions** → **Ежедневный дайджест СЗФО** → **Run workflow**
2. В поле «Дата в формате YYYY-MM-DD» укажите нужную (например, `2026-08-12`)
3. **Run workflow**
4. Через 5–10 минут отчёт появится в списке на главной странице

## Настройка расписания

Файл `.github/workflows/generate.yml`, строка `cron: '0 6 * * *'` — это запуск в 6:00 UTC (9:00 МСК). Формат стандартный cron. Например:
- `'0 5 * * *'` — 5:00 UTC (8:00 МСК)
- `'0 3 * * 1-5'` — 3:00 UTC только по будням

Изменение через веб-интерфейс: откройте файл в GitHub → карандаш (Edit) → правьте → **Commit changes**.

## Лимиты

- **GitHub Actions:** для публичных репозиториев — **безлимитно** (для приватных было бы 2000 минут/месяц).
- **GitHub Pages:** soft-limit 100 ГБ трафика в месяц, 10 сборок в час — на несколько сотен пользователей в день с запасом.
- **История:** копится в репозитории, размер файлов небольшой (десятки КБ на день) — на годы хватит.

## Диагностика

- **Workflow упал?** Actions → выберите неуспешный запуск → раскройте шаги, увидите лог. Чаще всего — временная недоступность API pravo.gov.ru; следующий запуск отработает.
- **Страница не открывается?** Settings → Pages: убедитесь, что источник — main / root, статус — «Your site is live at…».
- **За дату 0 наградных указов?** Это нормально: не каждый день Президент подписывает наградные указы. Пустая запись всё равно попадёт в архив.

## Что делает скрипт (кратко)

1. `GET /api/Documents?block=president&Date=…` — список указов Президента за день
2. Фильтр по `complexName`: о награждении / присвоении звания / объявлении благодарности / поощрении
3. `GET /file/pdf?eoNumber=…` — скачивание PDF
4. `pdfplumber` для текстового слоя, при неудаче — `pdf2image` (250 DPI) + `pytesseract` с русской моделью
5. Парсер награждённых: три типа заголовков наград, splitter-маркеры, склейка OCR-переносов, обрезка position_org
6. Матчер регионов СЗФО во всех падежных формах
7. Генерация HTML отчёта за день + обновление главной страницы со списком
