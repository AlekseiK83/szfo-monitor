# Суфлёр — разбор выступлений по зарплатному проекту

Веб-приложение (PWA) для менеджеров: записать презентацию → получить расшифровку → получить разбор по базе знаний ЗП и рубрике публичных выступлений с пошаговой самопроверкой выводов.

Все данные хранятся **в браузере** (IndexedDB): выступления, аудио, разборы, базы знаний, настройки и ключи. Сервера у приложения нет.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | разметка и стили |
| `app.js` | вся логика: хранилище, запись, Whisper, ИИ-конвейер, отчёты, история |
| `sw.js` | service worker: приложение открывается без сети |
| `manifest.webmanifest`, `icon.svg` | установка на главный экран телефона |

## Как опубликовать (GitHub Pages)

1. Положите файлы в репозиторий: в корень или в папку, например `suflyor/`.
2. Settings → Pages → Deploy from branch → `main` / root.
3. Откройте `https://<логин>.github.io/<репозиторий>/suflyor/`.

Нужен именно https: без него браузер не даст доступ к микрофону и не включит офлайн-режим. Локально запускайте через `python3 -m http.server`, а не открывайте файл двойным щелчком.

## Расшифровка

- **Живая во время записи** — Web Speech API (Chrome, Edge, Safari). Звук уходит в Google или Apple.
- **На устройстве** — Whisper (transformers.js 3.8.1): Base ≈80 МБ или Small ≈250 МБ. Модель скачивается один раз с huggingface.co, потом работает офлайн, звук не покидает устройство. На компьютере с WebGPU это в разы быстрее. Аудио режется по паузам на куски до 28 с; известные «галлюцинации» на тишине («Субтитры сделал…», «Продолжение следует…») отфильтровываются.
- **Из файла** — .txt, .vtt, .srt из Телемоста, SaluteJazz, Zoom, Teams.

## ИИ для разбора (Настройки)

- **Ручной режим** (по умолчанию, без ключа) — приложение готовит запрос, вы отправляете его в чат с Claude и вставляете ответ. Проверка идёт раундами.
- **Claude API** — свой ключ; запросы идут из браузера напрямую на api.anthropic.com.
- **OpenAI-совместимый шлюз** — корпоративный шлюз, GigaChat через совместимый прокси, Ollama или LM Studio. Шлюз должен разрешать CORS.

## Конвейер разбора

1. Метрики на устройстве: темп (в том числе по минутам), паразиты на 100 слов, канцелярит, «вы/мы».
2–4. Параллельно: структура, сверка с базой ЗП (верно / неточно / ошибка / нет в базе / недопустимое обещание), рубрика из 10 критериев.
5. Локальная проверка цитат: дословность или нечёткое совпадение от 80%.
6. Независимый проверяющий → исправление → повтор, пока уверенность не достигнет порога (95%, до 3 итераций).
7. Итог: балл /100, сильные стороны и зоны роста, «скажите иначе», упражнение.

«Точность по продукту» и «Темп» считаются кодом, а не моделью, чтобы оценка была воспроизводимой.

## Данные

- Резервная копия: Настройки → «Скачать резервную копию» (JSON, по желанию с аудио). Ключи API в неё не попадают.
- «Запретить браузеру очищать данные» — запрос `navigator.storage.persist()`. Установленное на главный экран приложение защищено надёжнее.
- Не записывайте клиентские данные: ФИО, суммы, условия договоров.
